## Featured projects

### Enterprise Knowledge Assistant

A production-oriented knowledge assistant combining semantic search with PostgreSQL full-text retrieval to ground responses in retrieved documents.

- Hybrid retrieval using pgvector and PostgreSQL FTS, combined with RRF and CrossEncoder reranking.
- Metadata filtering, token budgeting, and fallback responses when supporting context is insufficient.
- Retrieval evaluation using Precision@K, Recall@K, hit rate, and LLM-as-judge assessment.
- Async response streaming through FastAPI and Groq.

**Stack:** Python · FastAPI · Groq · Supabase · PostgreSQL · pgvector · React

### Autonomous Multi-Agent Workflow Engine

A LangGraph workflow that separates planning, research, and writing into distinct agent responsibilities.

- Router → Planner → Research → Writer workflow with conditional routing.
- Multi-step LLM and tool execution with structured state.
- Session-based conversational memory and context trimming.

**Stack:** LangGraph · LangChain · TypeScript · Groq · Supabase

### Enterprise Agentic AI Assistant

Contributed to an enterprise assistant that routes requests through supervisor orchestration and domain-specific tools.

- Enterprise API integration with validation and human-in-the-loop checkpoints.
- Controlled failure recovery using retries, circuit breakers, and escalation.
